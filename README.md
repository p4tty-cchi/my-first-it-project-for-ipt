# Personal Profile Webpage

The Personal Profile Webpage is a group activity developed for our Integrative Programming Technologies course. The project demonstrates the fundamentals of web development using HTML and CSS to create a simple, visually appealing webpage introducing our group. The webpage presents a short group introduction, hobbies, goals, a profile or favorite image, and a link to a favorite website or social media page. It serves as a practical application of basic HTML elements and CSS styling.

The project can be easily accessed through this link: https://incandescent-pony-9173b9.netlify.app/frontpage

**Technologies Used**

HTML5 – Used to structure the webpage and organize its content.

CSS – Used to style the webpage, apply background colors, customize fonts, add borders and padding, and center the content.

Web Browser – Used to view and test the webpage.

Visual Studio Code – Used as the code editor.


**Features**

Group name displayed as the main webpage heading.

Introduction describing the group, its interests, and goals.

List of hobbies or personal goals.

Profile picture or favorite photo.

Clickable link to a favorite website or social media page.

Customized background color, fonts, borders, and spacing.

Centered webpage content for a clean and organized layout.

**How to Run the Project**


Download or clone this repository to your computer.

Extract the ZIP file if you downloaded the project as a compressed folder.

Locate the main HTML file, named frontpage.html.


**Learning Objectives**


Through this activity, we practiced:

Structuring webpage content using HTML elements.

Applying CSS properties to improve webpage appearance.

Incorporating images and hyperlinks into a webpage.

Organizing information using headings, paragraphs, and lists.

Collaborating as a group to complete a basic web development project.
