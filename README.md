# my-first-it-project-for-ipt
A group activity for Integrative Programming Technologies, demonstrating basic HTML and CSS through a personal profile webpage.
This is a personal profile webpage developed as a group activity for our Integrative Programming Technologies course. This project demonstrates the fundamentals of HTML and CSS by creating a simple, styled webpage featuring our group introduction, hobbies, goals, profile image, and social media links. It showcases our understanding of basic web development, HTML elements, CSS styling, and webpage layout.
